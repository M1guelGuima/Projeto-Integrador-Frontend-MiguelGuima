# NexaNet — Projeto Integrador de Front-end

Projeto Integrador desenvolvido para a disciplina de Desenvolvimento Front-end do curso de Análise e Desenvolvimento de Sistemas (ADS).

## Sobre o projeto

A NexaNet é uma empresa fictícia de internet criada para representar um provedor de conexão por fibra óptica, com foco na região Nordeste.

O projeto apresenta um site institucional com informações sobre a empresa, seus planos de internet, funcionalidades interativas e uma central de atendimento.

## Tecnologias utilizadas

- **HTML5:** estruturação e semântica das páginas.
- **CSS3:** estilização, identidade visual e responsividade.
- **JavaScript:** interatividade, manipulação do DOM, validações e funcionalidades do site.

## Funcionalidades

- Apresentação institucional da NexaNet.
- Exibição dos planos de internet.
- Gráfico comparativo das velocidades dos planos Nexa Casual, Nexa Pro e Nexa Gamer.
- Carrossel de depoimentos fictícios.
- Menu lateral interativo.
- Formulário de contato com formatação e validação de CPF e telefone.
- Página com informações sobre o desenvolvimento do projeto.
- Apresentação em vídeo com legenda em português.

## Observações

O projeto é exclusivamente Front-end e não possui integração com banco de dados ou servidor Back-end.

O formulário de contato funciona como uma simulação, sem envio ou armazenamento real das informações.

## Objetivo acadêmico

Aplicar os conhecimentos adquiridos durante a disciplina de Desenvolvimento Front-end, explorando HTML, CSS e JavaScript na construção de uma aplicação web institucional.
